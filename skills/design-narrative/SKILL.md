# Creative narrative design

Announce once: **Using `design-narrative`**.

Authority: Theme 5 accepted (T5D narrative). **No single story method is SoT.**  
Run **`design-process`** spine first for non-trivial narrative work.

## When to use

- Story structure, quest design, interactive/branching narrative
- Binding story beats to player action / system state

**Out:** World bible / cast consistency → `design-world-character`. Pure mechanics balance → `design-systems`. Fan wikis as primary truth. Product UX (T5C).

## Method (plural — pick and state)

Examples of valid frames (not exhaustive):

- String-of-pearls vs story machine (Schell-class)
- Modular / graph quest structures
- Storylets + qualities / state
- Quest chains with explicit close conditions

Prefer designs that state **how beats touch game state** (flags, qualities, triggers, close conditions) when the product is interactive.

## Agent role

- Offer 2–3 narrative approaches with tradeoffs
- Critique pacing, agency, and ludonarrative conflict
- Human decides; keep lore dumps out of decision records — record *structure* choices

## Handoffs

| Need | Use |
|------|-----|
| Shared design spine / gate | `design-process` |
| Systems / world coupling | `design-systems` / `design-world-character` |
| After accept → plan | `implementation-plan` → `implementation-plan-verify` |
