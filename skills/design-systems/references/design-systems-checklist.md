# Creative systems checklist

- [ ] design-process spine / human gate
- [ ] Experience goals stated
- [ ] Dynamics/loops sketched before final numbers
- [ ] Mechanics listed as testable rules
- [ ] Plural-method note: which lens in use (MDA / Schell / other)
- [ ] Playtest or critique pass planned
- [ ] Not confused with narrative or world bible work
- [ ] Not used as software Dependency-Rule architecture
