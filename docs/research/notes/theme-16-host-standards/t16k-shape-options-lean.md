# T16K — Shape options lean

| ID | Shape | Pros | Cons |

## Agent lean (quality-over-ease)

Prefer **O1**:

1. Skill **`author-standards`** (name OPEN to tweak) — host feedstock authoring, not Toolbelt-universal law.  
2. Modes: **principles** (philosophy/tone/continuity) · **standards** (checkable profile) · **derive** (recon+history → proposed) · optional light **bind-check**.  
3. Templates: `docs/templates/principles-profile.md` + `docs/templates/standards-profile.md` (anatomy from T16E).  
4. **Keep** `implementation-closeout`; teach it to *reference* standards/principles (no rename this theme).  
5. Plan/Execute Handoffs: load profile paths when present; skip when absent.  
6. AGENTS.md: short pointers only.  
7. Conflict stack: design/ADR > principles > standards > inferred (proposed).  
8. Deep next (if needed): more exemplars (T16F), git-recency recipe (T16I), GitHub pack sampling.
