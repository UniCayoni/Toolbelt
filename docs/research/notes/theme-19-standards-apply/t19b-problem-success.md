# T19B — Problem / success

**Using `research-protocol`.** Depth: **normal**.

## 1. Scope

What fails with mega-context / soft-only bind; what “good apply” looks like for agents/subagents.

## 2. Findings

- `FACT` [E0] Theme 16 fences Toolbelt-universal law and always-on standards *rule bodies*; AGENTS stays pointer-thin. [E0: Theme 16 report D10/D12]
- `FACT` [E0] Standards template encourages one rules table (S1…) in a single profile file. [E0: `docs/templates/standards-profile.md`]
- `INFERENCE` [E4] Soft “load when present” on Plan/Execute/Closeout only → high miss rate when agents enter via side-door skills or subagents without re-reading AGENTS. Premises: T19A handoff map; no ambient gate.
- `INFERENCE` [E4] Loading an entire growing standards profile every turn fights selective-load intent and context budgets. Premises: single-file template; campaign brief selective-load goal.
- `INFERENCE` [E4] Success criteria for Theme 19: (1) absent/unaccepted → no-op; (2) router emits **pointers** not rule dumps; (3) worker loads only matched modules; (4) draft≠SoT preserved; (5) compose-only vs pocket routers. Premises: campaign brief vocabulary; Theme 14 router contract.

## 3. Success sketch (proposed — not SoT)

```text
Ambient gate (thin) → if no accepted catalog/modules: stop
Standards-router → classify action/wording/skill/path/intent → module ids + paths
Worker / subagent → read those modules only; cite in plan/execute/closeout as today
```
