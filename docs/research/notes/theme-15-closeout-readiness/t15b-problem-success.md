# T15B — Problem & success criteria

## 1. Scope

- Question: What should “useful closeout readiness” mean for Toolbelt, falsifiably?
- Out of scope: Final skill prose

## 2. Method

| Item | Value |
|------|-------|

## 3. Findings

- `CLAIM` [E4/session] Product thesis (human-accepted in scope): help hosts **define and check** closeouts from evidence + requirements; do **not** own commit/push/PR/merge. Premises: campaign brief + prior chat accept.
- `INFERENCE` [E4] Success if a surface can: (a) elicit/load a **host closeout profile** (criteria + evidence slots), (b) score readiness against **cited** Toolbelt/host evidence without inventing greens, (c) emit **ready | blocked | N/A** with gaps listed, (d) hand ceremony explicitly to host/human. Premises: T15A gap; draft≠SoT; cite-or-omit.
- `INFERENCE` [E4] Failure modes to design against: empty meta (“write your own checklist” with no structure); ceremony creep (`gh pr create` as skill spine); false ready (claiming verify without locator).
- `OPEN` Solo agent vs team — profile must scale from “I push main” to “org merge queue” via **slots**, not forked skills.

## 4. Non-goals (proposed)

- Universal Toolbelt PR body / merge strategy  
- Always-on closeout on trivial one-file tweaks  
- Replacing host CONTRIBUTING / Actions
