# T5C — Product / UX / UI (deferred)

**Not in the active Theme 5 deep campaign.** Kept so the Design pocket does not forget UX/UI.

## Why deferred

Normal scoping found Alexandria has **no dedicated UX/HCI shelf**; SE probes for UX return AI-coding false friends. Running deep T5C as web-scrape-only would be thin and easy to over-claim. Prefer waiting for a queryable evidence base comparable to other tracks’ RAG waves.

## Held question (unchanged)

How to design **UI, UX systems, interaction, information architecture** with/for agents?

## Readiness gate (any one sufficient to re-open)

Re-include T5C in a deep campaign when **at least one** of:

1. **Alexandria UX/HCI corpus** — ingest books/docs; `rag_probe` on UX process / a11y / design systems returns **strong** or solid **partial** with real UX sources (not vibe-coding books), **or**
2. **Queryable site corpus** — an official or high-signal site (or mirror) that agents can search with high hit quality for WCAG/HIG/design-system *methods* (not random blogs), documented in a short readiness note with example probes, **or**
3. **Human waiver** — explicit accept of web/E1-first deep T5C despite weak RAG (record in campaign brief amendments)

Until then: no T5C Wave 1 gatherers; no UX Design skill elevation from Theme 5.
