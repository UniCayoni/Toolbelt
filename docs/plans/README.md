# Plans

`docs/plans/YYYY-MM-DD-<slug>-plan.md`

- Template: [`docs/templates/plan-minimal.md`](../templates/plan-minimal.md)
- Skill: `implementation-plan` (Theme 6 accepted)
- Draft/unapproved plans are not SoT until executed under an accepted design gate (`draft-is-not-sot`)

Trivial one-file tweaks may stay chat-ephemeral.
